## Задача 1. Обработка больших данных в реальном времени
* **Парадигма:** Императивная
* **Язык программирования:** C++
* **Обоснование:** Скорость выполнения: поток 100 кадров/с с разрешением 4096×4096 формирует огромную нагрузку, поэтому языки со сборщиком мусора не подходят из-за пауз, которые приводят к потере кадров. C++ обеспечивает прямое ручное управление памятью, что позволяет избежать задержек и исключить потерю данных.

## Задача 2. Прототип ML-сервиса для прогноза погодных условий
* **Парадигма:** Объектно-ориентированная  и функциональная.
* **Язык программирования:** Python.
* **Обоснование:**
  * **Легкость создания и читаемость:** Дедлайн в 2 недели требует минимального семантического разрыва и быстрого написания кода.
  * **Экосистема и библиотеки:** Наличие готовых библиотек для анализа данных и машинного обучения (`scikit-learn`, `PyTorch`, `pandas`, `numpy`).
  * **Профиль нагрузки:** Расчет 1 раз в сутки позволяет не задумываться о скорости работы интерпретатора, а ресурсоемкая линейная алгебра  делегируется оптимизированным библиотекам на C/Fortran.
  * **Динамическая типизация:** Обеспечивает быструю смену алгоритмов и проведение экспериментов без задержек на перекомпиляцию.

## Задача 3. Интерактивный UI для торгового терминала
* **Парадигма:** Реактивная и декларативная.
* **Язык программирования:** TypeScript.
* **Обоснование:**
  * **Среда выполнения и надёжность:** TypeScript проверяет типы данных заранее, поэтому виджеты не сломаются из-за случайных ошибок в структуре данных (В js эти ошибки могут возникнуть).
  * **Реактивность:** Данные с сервера WebSocket и REST API идут непрерывно. Реактивный подход позволяет виджетам автоматически обновляться сразу при изменении данных без сложной ручной логики.
  * **Скорость отклика (< 16 мс):** Интерфейс обновляет на экране только те цифры и графики, которые реально изменились, не перерисовывая всю страницу. 
  * **Тестируемость:** Логику обработки данных и обновление виджетов можно легко протестировать авто тестами отдельно от самого сайта и браузера.

## Задача 4. Прошивка для устройства регистрации температуры
* **Парадигма:** Императивная.
* **Язык программирования:** C.
* **Обоснование:**
  * **Ограниченность ресурсов:** 32 КБ оперативной памяти и 256 КБ флеш-памяти слишком малы для языков с виртуальными машинами или сборщиками мусора. .
  * **Прямой доступ к железу:** C позволяет напрямую управлять регистрами микроконтроллера, например к датчиком температуры с помощью указателей.
  * **Предсказуемость времени :** Код на C переводится в простые процессорные команды без внезапных скрытых пауз, поэтому датчик реагирует на события всегда за строго фиксированное время.
  * **Переносимость:** Код на стандартном C можно легко перенести на любой другой микроконтроллер, заменив только небольшую часть.
