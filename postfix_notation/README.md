# Постфиксная стековая машина

## Операции

- `+`, `-`, `*`, `/` — стандартные бинарные операции (с проверкой деления на 0).
- `~` — специальный оператор:
  - если $x \neq 0$ и $y \neq 0$: модуль разности $|x - y|$;
  - если $x = 0$ или $y = 0$: сумма всех элементов стека (включая извлеченные операнды), возведенная в квадрат.

---

## Запуск

Выражение передается через аргументы командной строки в кавычках (чтобы оболочка не раскрывала `~` в путь):

```bash
python3 main.py "3 0 4 ~ 2 ~"
```

Пример вывода:
```text
Шаг  1: токен '3' -> стек: [3]
Шаг  2: токен '0' -> стек: [3, 0]
Шаг  3: токен '4' -> стек: [3, 0, 4]
Шаг  4: токен '~' -> стек: [49]
Шаг  5: токен '2' -> стек: [49, 2]
Шаг  6: токен '~' -> стек: [47]

3 0 4 ~ 2 ~ = 47
```

Второй пример из ТЗ:
```bash
python3 main.py "2 2 + 4 - 4 ~ 2 3 * +"
# Результат: 22
```

Справка:
```bash
python3 main.py --help
```
