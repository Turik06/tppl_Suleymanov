# Доклад по теме: WebAssembly 

## Структура директории
* `index.html` — презентация на Reveal.js (строгий академический стиль, белый фон, черные буквы, без эмодзи/стикеров, встроенные заметки докладчика к каждому слайду).
* `demo/math.c` — исходный код рекурсивного факториала на C.
* `demo/math.wat` — текстовый формат байткода WebAssembly (S-выражения).
* `demo/math.wasm` — бинарный модуль WebAssembly (62 байта).
* `demo/run_node.js` — консольный запуск модуля через Node.js.

---

## Запуск презентации

### Способ 1. Локальный HTTP-сервер (Рекомендуется)
Из директории `tppl` выполните:
```bash
python3 -m http.server 8000 --directory presentation
```
Затем откройте в браузере: `http://localhost:8000`

### Способ 2. Прямой запуск
Откройте файл `presentation/index.html` в любом современном браузере.

---

## Горячие клавиши при выступлении
* **Клавиша `S`** — режим докладчика (**Speaker View**). Открывает отдельное окно со шпаргалкой (текст речи к текущему слайду), таймером выступления и превью следующего слайда.
* **Клавиши `Вправо` / `Влево`** (или **Пробел**) — навигация по слайдам.
* **Клавиша `F`** — переход в полноэкранный режим.
* **Клавиша `ESC`** — обзорная сетка всех слайдов.
