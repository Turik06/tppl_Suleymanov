# Токенизатор

Лексический анализатор, преобразующий исходный код программы в последовательность токенов.

## Распознаваемые токены

- `IDENT` — идентификаторы (`x`, `val_1`)
- `KEYWORD` — ключевые слова (`if`, `else`, `while`, `return`, `for`, `def`)
- `INT` — целые числа (`42`, `0`)
- `FLOAT` — вещественные числа (`3.14`, `1.`)
- `STRING` — строковые литералы (`"hello"`, `""`)
- `OP` — операторы (`+`, `-`, `*`, `/`, `=`, `<`, `>`, `==`, `<=`, `>=`)
- `SEP` — разделители (`(`, `)`, `{`, `}`, `,`, `;`)

Пробелы, табуляция и комментарии (от `#` до конца строки) пропускаются.

## Запуск

```bash
python3 main.py <путь_к_файлу>
```

Каждый токен выводится в формате `(<тип>, <значение>, <строка>:<столбец>)`. Нумерация строк и столбцов начинается с 1.

Пример для `x = y * 2`:
```text
(IDENT, x, 1:1)
(OP, =, 1:3)
(IDENT, y, 1:5)
(OP, *, 1:7)
(INT, 2, 1:9)
```

## Ошибки

При недопустимом символе или незакрытой строке сообщение выводится в `stderr`:
```text
<файл>:<строка>:<столбец>: lexical: <сообщение>
```

Коды возврата:
- `0` — файл успешно разобран;
- `1` — лексическая ошибка или ошибка чтения файла;
- `2` — неверные аргументы командной строки.

pip install -r requirements.txt
```

pytest --cov=main --cov-branch --cov-report=term-missing
```
